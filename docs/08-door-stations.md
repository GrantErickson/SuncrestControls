# Door stations

Every door station is a Stream Deck +, the same as the rack, with the same pages. Start with a sensible height and each door [locked out of the pages it doesn't need](07-companion-setup.md#lock-a-door-out-of-pages), and add a PIN lockout or covers only if real use shows a need. Both starting steps are free, and a door's pages can be changed later without touching the wall.

| Protection | Stops | Cost | Downside |
| --- | --- | --- | --- |
| Lock each door out of pages | iPad Mode, playlists, single light areas, Bluetooth, single zones and single TVs at the doors | Free | Home stays open to anyone |
| Mounting toward the top of the reach range | Small children | Free | Check accessibility rules first |
| [Companion PIN lockout](https://github.com/bitfocus/companion/blob/main/docs/user-guide/3_config/settings.md) | Anyone without the code | Free | Slower for volunteers |
| Lockable clear cover | Everyone without a key | Low | Someone has to find the key |

US accessibility rules commonly cap controls at about 48 inches above the floor. Ask your architect what applies before mounting higher.

## The deck

Every station is a [Stream Deck +](https://www.bhphotovideo.com/c/product/1972608-REG/elgato_stream_deck_with.html/overview): 8 keys, a touch strip and 4 dials. Using one deck everywhere means any deck can replace any other, and one spare covers every station. The test + already runs on a Network Dock.

The cost is a less wall-friendly shape. I found no Elgato wall mount for the Stream Deck +, and its dials need room for fingers, so plan on a shallow shelf or a custom angled plate at each door, the same as at the rack.

The 15-key [Stream Deck Module](https://www.elgato.com/ww/en/p/stream-deck-module-15-keys), which suits a flush wall better, was the earlier plan for the doors. It has no dials or touch strip, so choosing it again would mean separate door pages.

## Mounting

Elgato's overview doesn't list the dock's size, so measure one first. The dock [comes with a mounting bracket](https://www.elgato.com/explorer/products/stream-deck/stream-deck-network-dock-overview/) and a 15 cm USB-C cable.

1. Before the walls close, test-fit a Stream Deck + and a dock in the box or shelf you plan to use.
2. Terminate the Cat6 inside the box, with room for the dock and a USB-C loop.
3. Make a laser-cut or 3D-printed plate or shelf that holds the deck, hides the USB-C cable, and leaves room to turn the dials.
4. Use tamper-resistant screws, because a surface-mounted deck unplugs with one tug.
5. Leave air around the dock.
6. Label each plate with its door number, so support calls are easy.

Dim the door decks in Companion with **Surface: Set to brightness**. You can drop brightness overnight once the schedule is running.
